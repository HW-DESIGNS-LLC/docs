Getting started

From the box to your first upload

The board arrives ready to use — no soldering, no drivers. Steps 1–2 get the built-in demo online; steps 3–4 set you up to write your own code.

  1. 1

    Plug it in

    Connect the board to any USB‑C charger or computer port. It powers up and starts the built-in Weather Clock on the OLED display.

  2. 2

    Put it on your Wi‑Fi

    On first boot the board creates its own Wi‑Fi network called HW‑WeatherClock. Join it from your phone and a setup page opens (or go to 192.168.4.1). Pick your home network, enter its password, and set your city and °F or °C. The board restarts and shows your local time and weather, with the RGB LED tinted by the temperature outside. To change Wi‑Fi or city later, hold BOOT for 3 seconds.

    The board uses 2.4 GHz Wi‑Fi. If your router broadcasts separate 2.4 GHz and 5 GHz names, choose the 2.4 GHz one.

  3. 3

    Set up the Arduino IDE

    Install the free Arduino IDE, then open File → Preferences and paste this into Additional boards manager URLs:

    https://espressif.github.io/arduino-esp32/package_esp32_index.json

    Open Tools → Board → Boards Manager, search for esp32, and install esp32 by Espressif Systems. Then match these settings under Tools:

    BoardESP32S3 Dev Module
    USB CDC On BootEnabled
    Flash Size8MB (64Mb)
    Partition Scheme8M with spiffs

    No driver install is needed — the board uses the ESP32‑S3’s native USB, which Windows 10/11, macOS, and Linux recognize out of the box.

  4. 4

    Upload your first sketch

    Select the board’s port under Tools → Port, paste this in, and click Upload. The onboard LED cycles red, green, blue:

    #define RGB_PIN 48   // onboard RGB LED

void setup() {}

void loop() {
  neopixelWrite(RGB_PIN, 40, 0, 0);  delay(400);  // red
  neopixelWrite(RGB_PIN, 0, 40, 0);  delay(400);  // green
  neopixelWrite(RGB_PIN, 0, 0, 40);  delay(400);  // blue
}

    If the port doesn’t appear or the upload won’t start: use a data-capable USB‑C cable, or hold the BOOT button while plugging the board in, then try again.

  5. 5

    Keep going

    Take the board tour below, grab the pinout diagram and user guide, then build something from the example projects — including the full source of the Weather Clock your board shipped with.

Board tour

Know your board

Both sides, and what everything on them does. Renders show the bare board — the OLED display mounts on the front. Photos show the V1.0 prototype; V2.0 boards add pin labels on the front and use a smaller JST‑PH battery connector.

Front

  • ESP32‑S3 module up top — the green area is the Wi‑Fi antenna; keep it clear of metal.
  • EN (reset) and BOOT buttons, with the RGB status LED between them.
  • USB‑C for power, charging, and programming.
  • CHG and SYS ON indicator LEDs by the USB port.
  • Qwiic / STEMMA QT connector (JST‑SH 4‑pin) for solder-free I²C sensors.
  • Pin names printed beside every header pin, so you can wire it up without flipping the board.

Back

  • Every header pin labeled on the back too — power (3V3, GND, 5V_IN), GPIO numbers, and TX/RX.
  • 30‑pin ribbon connector for the OLED display.
  • LiPo battery connector (JST‑PH 2.0 mm) with polarity marked + / −.
  • Board revision code printed along the edge — include it when you contact support.

Where’s the screen?

These renders show the bare board. The 0.96″ OLED sits on the front; its ribbon cable passes through the center slot to the connector on the back.

Best Wi‑Fi range

Let the antenna end hang over the edge of your breadboard or enclosure. Metal, batteries, and hands near the green area reduce range.

Before you plug in a battery

Use a single-cell 3.7 V LiPo (600 mAh or larger) with a JST‑PH 2.0 mm plug and match the + / − marks on the board. Battery lead polarity is not standardized between vendors — check every new battery.

My computer doesn’t see the board

Use a data-capable USB‑C cable — many bundled cables are charge-only. No drivers are needed on Windows 10/11, macOS, or Linux. If the port still doesn’t appear, hold the BOOT button while plugging the board in, then release it and check again.

Which battery does it take?

A single-cell 3.7 V LiPo, 600 mAh or larger, with a JST‑PH 2.0 mm plug — the socket is on the back of the board. It charges automatically from USB‑C at ≈300 mA, and on-board protection guards against over-charge, over-discharge, over-current, and reverse polarity. Running the Weather Clock with Wi‑Fi always on, the board draws about 70 mA — roughly 14 hours per 1000 mAh (measured on a full discharge). When the battery runs low, the Weather Clock shows “charge me” and goes to sleep; plug in USB‑C to wake it. Match the + / − marks next to the connector — battery lead polarity varies between vendors.

Which board revision is this page for?

Board revision V2.0 — the code EE2026003B is printed along the back edge. The DVT report covers the V1.0 prototypes (Rev A, code EE2026003A). V2.0 uses a JST‑PH 2.0 mm battery connector (was JST‑XH), charges at ≈300 mA (was ≈200 mA), and adds pin labels on the front.

Can I use something other than Arduino?

Yes. It’s a standard ESP32‑S3 (8 MB flash, no PSRAM), so ESP‑IDF, MicroPython and CircuitPython should work with their generic ESP32‑S3 builds — we haven’t tested them yet. We test with Arduino and ESPHome; use the pinout for the display, LED and button pins.
